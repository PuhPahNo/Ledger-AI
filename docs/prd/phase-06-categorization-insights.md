# Phase 06 PRD: Categorization And Insights

## Goal
Provide tax-oriented categorization and spend insights across all businesses.

## Requirements
- Support global and per-business categories.
- Support prioritized rules: `merchant_contains`, `merchant_exact`, `plaid_category`, and `amount_range`.
- Apply categorization during transaction sync.
- Persist alerts for missing receipts, orphan receipts, duplicate subscriptions, spend spikes, and reauth issues.
- Dismissed alerts stay dismissed until regenerated by new facts.

## Acceptance Criteria
- Category aggregates power the dashboard categories tile.
- Rule matching unit tests pass.
- `insights.generate` job can rebuild open alerts.
- Alert dismiss endpoint persists status.
